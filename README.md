# Ramis Web App — dashboard sample

Single-file demo of the Ramis grower-facing web application. Open `index.html` in a browser, or publish the folder with GitHub Pages.

- No build step, no dependencies, no backend. Everything is in `index.html`.
- Sign in with any email and password to reach the dashboard.
- All data is illustrative sample data generated for the demo. Camera feeds and observation images are simulated.

## Pages

Dashboard · Farm & fields · Robots · Robot control · Pest monitoring · Observations · Alerts · Analytics & reports

## Product principle

The app is built around one question for the grower: *what should I do now?*
Observe → Detect → Understand → Decide → Act → Measure.

Raw counts are never shown alone. Each observation carries position, time, and the lamp and fan settings at capture, so passes can be normalised and compared across zones. Zone F is an untraversed control zone.
